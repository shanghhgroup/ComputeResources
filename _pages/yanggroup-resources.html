如何选择计算资源

以下是根据资源类型给出的使用建议；实际软件兼容性、性能和资源额度需在目标服务器确认。

CPU 计算与批量作业

本组日常 CPU 计算可先参考 HFNL 手册。需要更多 CPU 资源时，可申请 YangGroup 集群。Cluster9 使用 PBS，Cluster10–12 使用 Slurm。

GPU / CUDA 计算

需要 GPU 加速时，可申请 YangGroup 的 V100 服务器。先确认程序对 V100、驱动及 CUDA 版本的要求，再协调所需卡数和运行时长。

需要单节点较多 CPU 核心时，可向管理员询问 Cluster10 的 144 核 fat 节点或 Cluster12 的 128 核节点；需要大内存时，应先核实内存容量和可申请额度。

申请与使用

  1. 说明任务需求。准备 CPU / GPU 类型、预计核数或卡数、内存或显存需求、运行时长和软件环境。
  2. 通过组内渠道联系管理员。申请目标平台账号，确认 ShangGroup 成员权限、资源配额和使用规则；已有 HFNL 账号不代表其他集群已开通。
  3. 获取内部接入说明。登录地址、认证方式和远程接入安排由管理员提供。{{ resources.access_support }}
  4. 按目标平台提交任务。Cluster9 按 PBS 规则；Cluster10–12 按 Slurm 规则。GPU 服务器先确认管理员安排，再运行作业。
  5. 小规模测试后扩大计算。检查环境、实际资源占用和输出，及时整理数据并释放资源。

本网站原有 Slurm 手册针对 ShangGroup HFNL 的通用流程；在 YangGroup 集群上使用时，需按目标平台修改队列、资源参数和环境设置。PBS 和无调度系统的 GPU 服务器应遵循各自的内部说明。
