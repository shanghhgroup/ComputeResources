## 1. 本组 HFNL 不含 GPU

ShangGroup 本组的 HFNL **2 节点服务器提供 CPU 计算资源，不含 GPU**。需要 GPU 的组内成员可按规则申请上级实验室 YangGroup 的 GPU 服务器。

## 2. YangGroup GPU 资源入口

{% include compute-totals.html %}

依据《YangGroup 服务器用户手册》（核对日期：{{ resources.reviewed_on }}），清单包含 {{ resources.gpu_servers | size }} 台 GPU 服务器，共 {{ yang_gpu_count }} 张 NVIDIA V100。具体设备、卡数、统计口径及申请流程见：

**[查看 YangGroup GPU 服务器清单]({{ '/yanggroup-resources/#gpu-resources' | relative_url }})**

原手册将这些 GPU 服务器标注为无作业调度系统。请先联系管理员确认账号权限、GPU 分配、显存和软件环境；本组 HFNL 的 Slurm 脚本不应直接套用到这些服务器。

## 3. 只有本组 CPU 账号时

在本组 HFNL 上，仍可运行：

- CPU 版本的预处理和后处理脚本；
- 小规模模型调试；
- 不依赖 CUDA 的科学计算程序；
- 使用 CPU 后端的 PyTorch / NumPy / SciPy 程序；
- 需要 GPU 的正式任务，先申请 YangGroup GPU 资源，再迁移程序与输入。

## 4. 获取 GPU 权限后

在获准使用的 GPU 服务器上，可按内部规则使用下面命令检查 GPU 状态。可见的空闲设备不等于已获分配，运行前仍应确认使用安排。

```bash
nvidia-smi
```
